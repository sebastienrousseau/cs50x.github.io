# Academic Honesty & Collaboration Policy

CS50x Hub strictly adheres to the principle that true learning requires active problem solving.

## What is Encouraged:
- Discussing algorithmic approaches in high-level pseudocode.
- Explaining C syntax, compiler warnings, and Valgrind outputs.
- Creating conceptual mental models and memory diagrams.

## What is Prohibited:
- Sharing or publishing complete problem set source code.
- Soliciting or viewing exact line-by-line solutions before completing your own work.
